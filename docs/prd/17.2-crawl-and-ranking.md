# PRD: the crawl and the ranking

- **Kind:** feature · **Spec:** [.spec/17-openalex.md](../../.spec/17-openalex.md) (slice 17.2)

## Problem / motivation

The wiki's PI curates `raw/` from memory, and [the skill's](../../skills/crux-wiki/SKILL.md)
own semantic-lint checklist hands *"a question the wiki can't answer yet → suggest a source
for the PI to add"* to the agent — which answers from training data. This slice replaces the
guess with arithmetic over the citation graph.

## Design decision

One new verb, `crux lit crawl <slug>`, in `openalex.py` (the impure side of spec 05's purity
line). Seeds are every `raw/` source carrying an OpenAlex work id, plus any `--seed W…`.
Backward is `referenced_works`; forward is `cites:` sorted by citation count, capped at the
top 200 per work. Depth 2 expands only from depth-1 works that at least two seeds reach.

Output is `wiki/lit/<slug>/candidates.tsv`, **git-tracked** — this answers the spec's first
open question. It is the record of what the PI chose from, and it is small. The response
cache under `wiki/.openalex/` stays untracked.

### The score

```
reach(c) = (distinct seeds reaching c at depth 1) + 0.5 × (distinct hubs reaching c at depth 2)
score(c) = reach(c) / log10(10 + max(citations(c), 100))
```

Ties break on citation count, descending.

**Both halves of this differ from what the PRD was approved with, because the manual
criterion — read a real crawl's top 20 — failed, which is exactly the job that criterion
exists to do.** The first run, over three chromatin-segmentation seeds, returned
*"Bibliography (2015)"*, *"Additional file 2 of NucHMM"* and *"SynJax: Structured Probability
Distributions for JAX"* in its top 20, while the ENCODE 234-epigenome paper sat at rank 48.
Two causes, both now fixed and both asserted:

1. **Depth-2 reach was inflated.** A hub reached by 3 seeds credited all 3 to each of its 200
   citers, so anything citing a popular hub scored as though the whole seed set pointed at it
   — 45 of the top 50 were citers-of-hubs. Reaching a hub is not reaching the seeds. Depth 2
   now counts **distinct hubs**, at half a point each.
2. **The divisor rewarded obscurity.** `log10(10 + citations)` is smallest at zero citations,
   so among works of equal reach the most obscure won. It was only ever meant to demote the
   far right tail. A floor of 100 citations makes the divisor flat at the low end, where
   reach alone decides.

*Rejected:* ranking by `cited_by_count`, which returns the field's furniture. *Rejected:*
depth 3 — ~320,000 works, and the reach signal dilutes past the point where it means anything.

### Duplicate seed records

OpenAlex carries more than one record for the same paper (a preprint, a second deposit), each
with its own id. Excluding seeds by work id alone let a seed's own twin come back **ranked
first** in the real crawl. Candidates are now also dropped on a normalized-title or DOI match
against a seed.

## Scope — what this does not do

No scoping conversation (17.3). No PDF download and no auto-ingest (17.4). No topic filter and
no year window — both are one-line filters, better added when a real crawl shows they are
needed than guessed now. No vector search, no retraction check.

## Acceptance criteria

- [x] `reach` and `score` are correct on a frozen fixture graph, by hand-checked arithmetic,
      including a 100,000-citation work reached only through hubs ranking last.
- [x] A depth-2 work counts the hubs that reach it, not those hubs' seeds.
- [x] Below the citation floor, equal reach scores equal, and the better-cited work wins.
- [x] A seed, a work already in `raw/`, and a duplicate record of a seed are never candidates.
- [x] Depth-2 expansion happens only from depth-1 works with reach ≥ 2, asserted by the set of
      queries actually issued against a stubbed boundary.
- [x] A re-run from a warm cache makes no network call and produces a byte-identical TSV.
- [x] A crawl that cannot finish inside the remaining daily budget refuses rather than
      returning a partial list.
- [x] Zero seeds is a `CruxError` telling the PI to ingest with `--doi` first, not an empty file.
- [x] `engine.py` still imports no `urllib`; selftest green and offline from a fresh clone
      with no key (2050 → 2067).
- [x] (manual) A real crawl from 3 chromatin-segmentation seeds. Its top 8 is now Ernst &
      Kellis 2010, Ernst 2011, joint chromatin-state/conformation annotation, ChromImpute,
      Day 2007, ChromHMM 2017, the Libbrecht segmentation review and EpiMap. MACS (20,484
      citations) fell to rank 172 and deepTools2 (9,305) to 567, while ENCODE's encyclopedia
      (19,712) stayed at rank 11 because the seeds genuinely reach it — which is the divisor
      behaving as designed rather than blindly punishing popularity.

## A note on the budget check

The daily budget is only knowable from a response header, so the check runs after the first
cheap request rather than before any request at all, as the PRD first put it. There is no way
to ask OpenAlex what is left without asking OpenAlex something. It still refuses before the
bulk phases, which is what the criterion is for: half a candidate list looks complete and is not.

## Backward-compat / migration

None. New files under `wiki/lit/`; no format change, no verdict change. `ENGINE_VERSION`
stays 3.4.
