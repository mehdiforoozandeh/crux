Does more data beat a better model, once both get the same budget?

Three experiments, two tasks, every arm run with seeds (independent random restarts) and scored twice: once at each arm's own cost, once at equal training compute.

Motivationthe problem

In the usual comparison, data size is confounded with compute (both change together)

Doubling the training set also doubles training compute. A win for the data arm is then a win for more data and a win for more compute at once, and the comparison cannot tell them apart.

Motivationthe question

If we can afford either twice the data or a bigger model, which one buys more accuracy, when both arms spend the same compute?

Pre-registered (fixed in writing before any run): the model families, the training recipe, the seed count, and running every comparison at both budgets.

Because the design was pre-registered, no budget choice was made after seeing a result.

Methodwhat we score

The outcome is the accuracy difference: data arm minus model arm

Each difference carries its 95% confidence interval (range holding the true difference in 95% of repeats) across seeds. A difference is statistically significant (unlikely from chance alone) only when that interval excludes zero; otherwise it is labelled not significant, and stays on the slide.

Above zero, the data arm wins. Below zero, the model arm wins. The line through each point is its confidence interval; a line that crosses zero marks a difference that is not significant.

Discussionwhat this rules in and out

Most of the data advantage was the extra compute

Ruled out

More data beats a better model in general: it reverses at equal compute, on both tasks.

Ruled in

At each arm's own cost the data arm wins on the first task, and that result replicates.

Limitations

Two tasks and one pair of model families. Matching compute shortens the data arm's training, which may not be the only fair match.

Discussionoptions for the next phase

Options for the next phase

Option A

Find the data floor: how little data still matches the better model. Cheap; teaches where the curve bends.

Option B

Match compute a second way, by growing the model arm instead. Medium cost; tests the matching rule itself.

Option C

Repeat on data from another source. Costly; tests whether any of this transfers.

These are options, not recommendations. Each card says what it costs and what it would teach.
