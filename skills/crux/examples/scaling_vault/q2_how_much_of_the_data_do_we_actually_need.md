# q2 — How much of the data do we actually need?

Parent:: [[more_data_or_a_better_model]]

## Question

If the data lever is weaker than it looked, the operational question is the marginal return at our own scale ([[wiki/sample-efficiency]]) rather than the average return over a curve someone else measured. Collection has a price, and a programme needs the point where paying it stops being worth it.

## Answer so far

The training set can be halved at almost no cost, but not cut to a tenth. The collapse lies between those two, and that is where the next round should look — which also means most of the data we are paying to collect is buying very little.
