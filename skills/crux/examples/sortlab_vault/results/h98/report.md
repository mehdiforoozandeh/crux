# h98 — run report

**Claim.** The counter clock has a finer step than the wall clock

**Measured.** Counter clock step was 0.001 ms. Wall clock step was 0.050 ms. Counter was 50 times finer.

**What the run showed.** The counter clock has a step size about fifty times smaller than the wall clock. This means it can measure gaps that the wall clock would round to zero. Both clocks measured the one-hundred-millisecond sleep accurately, within one percent.
