# Glossary

_The project's specialist vocabulary — the words this project has agreed on. A term listed
under `## Terms` may be used bare, in a node or in conversation. Anything else must be
glossed in the same breath, or asked about._

_This file starts empty on purpose. A seeded glossary would put words in your mouth._

## Terms

- **crossover point** — the list size where one sort stops losing and starts winning
- **doubling ratio** — the time at size 2n divided by the time at size n
- **median of repeats** — the middle time of many repeats, used instead of the mean
- **nearly-sorted list** — a list where only a small share of items sit out of place
- **run** — a stretch of the list that is already in order
- **shape of the list** — which pattern a test list has: random, sorted, reversed, nearly, duplicates
- **timer resolution** — the smallest gap in time my clock can actually tell apart
- **warm-up run** — the throw-away run before timing, so the slow first pass is not counted
